# হাতেকলমে

নবম-দশম শ্রেণির শিক্ষার্থীদের জন্য ইন্টারঅ্যাকটিভ বিজ্ঞান শেখার প্ল্যাটফর্ম। প্রতিটি অধ্যায়ে দুটি অংশ: **তত্ত্ব** (গোছানো নোট ও কুইজ) এবং **ল্যাব** (অ্যানিমেশন ও হাতে-কলমে অনুশীলন)।

## চালানো

```
npm install
npm run dev        # http://localhost:5173
npm test           # নোট ও কুইজের তথ্য যাচাই
npm run build      # dist/ ফোল্ডারে তৈরি হয়; যেকোনো static hosting-এ রাখা যায়
```

সার্ভার বা ডেটাবেজ লাগে না। শিক্ষার্থীর অগ্রগতি তার নিজের ব্রাউজারে জমা থাকে।

## নোট সম্পাদনা

নোট আছে `src/subjects/biology/notes/ch01.md` ... `ch14.md` ফাইলে। কোড না জেনেও লেখা বদলানো যায়:

| লেখার ধরন | কীভাবে লিখবেন |
| --- | --- |
| অংশের শিরোনাম | `## শিরোনাম` |
| ছোট শিরোনাম | `### শিরোনাম` |
| তালিকা | `- আইটেম` |
| সংজ্ঞা | `: পরিভাষা \| অর্থ` |
| সারণি | `\| ঘর \| ঘর \|` (প্রথম সারি শিরোনাম) |
| সূত্র | `= সূত্র` |
| জরুরি তথ্য | `! লেখা` |
| সতর্কতা | `!! লেখা` |
| মোটা অক্ষর | `**লেখা**` |

কুইজ আছে `src/subjects/biology/quiz.ts` ফাইলে।

## নতুন বিষয় যোগ করা (পদার্থবিজ্ঞান, রসায়ন)

1. `src/subjects/biology` ফোল্ডারের মতো `src/subjects/physics` তৈরি করুন: `index.ts`, `quiz.ts`, `notes/`, `labs/`।
2. `src/subjects/index.ts`-এ `physics`-এর `soon` এন্ট্রি বদলে নতুন বিষয়টি যুক্ত করুন।

পাতা, রাউটিং, কুইজ ও অগ্রগতি আপনাআপনি কাজ করবে। ল্যাবের সাধারণ অংশ (`Seg`, `Range`, `StepNav`, `SortGame`, `OrderGame`) আছে `src/components/labkit.tsx`-এ।

## ল্যাবের নকশা

জীববিজ্ঞানের প্রতিটি অধ্যায়ে একই ধারা অনুসরণ করা হয়েছে:

- **কারণ ও ফলের মডেল:** `labs/models/` ও `labs/cell/` ফোল্ডারের মডেল থেকে ল্যাবের ফল আসে, হাতে বসানো লেখা থেকে নয়।
- **আগে অনুমান, পরে পরীক্ষা:** `PredictBox` শিক্ষার্থীকে আগে উত্তর বেছে নিতে বলে। প্রতিটি পরীক্ষার উত্তর মডেলের সাথে মিলছে কি না, পরীক্ষা (`npm test`) তা যাচাই করে।
- **অঙ্গাণু কাছ থেকে দেখা:** `labs/cell/closeups.ts` প্রতিটি অঙ্গাণুর ইনপুট, ধাপ ও উৎপাদ ধরে রাখে। হিসাব বইয়ের সমীকরণের সাথে মেলে কি না, পরীক্ষায় যাচাই হয়।
- **সৃজনশীল অনুশীলন:** `labs/cases/` ফোল্ডারে ক, খ, গ, ঘ স্তরের মৌলিক উদ্দীপক আছে।

## বাস্তবসম্মত ছবি

`labs/paint/` ফোল্ডারের রেন্ডারার আকৃতিকে ফুলিয়ে আলো-ছায়াসহ জৈবিক তলে রূপ দেয় (`inflate`), আর `leaf.ts` পিক্সেল ধরে পাতা আঁকে। সব ছবি কোড থেকে তৈরি, তাই কোনো ছবি ডাউনলোড করতে হয় না। পঞ্চম অধ্যায় এভাবে তৈরি; অন্য অধ্যায়েও একই রেন্ডারার ব্যবহার করা যাবে।

## নতুন ল্যাব যোগ করা

`labs/` ফোল্ডারে একটি React কম্পোনেন্ট লিখে `src/subjects/biology/index.ts`-এ সংশ্লিষ্ট অধ্যায়ের `labs` তালিকায় যোগ করুন। প্রতিটি ল্যাব আলাদাভাবে লোড হয়, তাই ল্যাব বাড়লেও শুরুর পাতা ভারী হয় না।
